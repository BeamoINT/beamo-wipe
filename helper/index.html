The USB is missing or not listed

  1. Keep this USB plugged in while the computer restarts. Do not remove it.
  2. Use a USB-A or USB-C port on the computer itself. Avoid a keyboard, monitor, or hub if you can.
  3. Try a different port on the same computer.
  4. Restart and look for this USB in the boot menu, or in Windows Use a device.
  5. If this computer still never lists the USB, open the USB on a computer that already shows files and confirm START-HERE.html is there. Then try another direct port.

Windows 11: Settings → System → Recovery → Advanced startup → Restart now → Use a device, if it is listed. Windows 10: Settings → Update & Security → Recovery → Advanced startup → Restart now → Use a device. Those menus are for UEFI PCs. See Windows 11 and Windows 10.

Technical detail

Some computers hide USB startup until firmware allows USB boot. That is a firmware setting on the computer, not a Beamo setting. If you might use this Windows installation again, confirm the BitLocker recovery key first. This page cannot change firmware.

The boot-menu key does nothing

  1. Keys vary by manufacturer. They are not the same on every PC. Use the typical keys table.
  2. Start tapping the key as soon as you restart — before Windows or a logo finishes.
  3. On HP, try Esc first, then F9.
  4. If the computer starts too quickly to catch a key, use the Windows Settings steps instead of changing firmware.
  5. Check the sticker, the startup screen, or the computer manufacturer’s instructions if a listed key does nothing.

Dell, Lenovo, and Acer often use F12. ASUS often uses F8 or Esc. MSI often uses F11. Gigabyte often uses F12. Intel Mac: Option (⌥) at startup. Not Apple Silicon.

Technical detail

Some computers shorten the moment when a key is accepted. Windows Recovery Environment Use a device avoids that race on many UEFI PCs. Do not treat firmware, boot-order, or setup-menu changes as the next automatic step.

The computer refused the USB

  1. If you might use this Windows installation again, confirm you can reach the BitLocker recovery key before any firmware change. If you cannot find the key, stop. Use another USB port or the Windows steps instead. See BitLocker.
  2. Write down the exact on-screen message. Reaching a boot menu does not mean an erase has started.
  3. Try another direct USB port and restart.
  4. On older BIOS computers, Use a device may be missing. Use the boot-menu key instead of firmware changes.
  5. Use the computer manufacturer’s startup instructions. This helper does not change Secure Boot or bypass a refusal.

See Secure Boot for what this USB ships. Do not treat firmware or Secure Boot changes as the next automatic step.

Technical detail

This build uses Debian's signed boot components. Whether your computer accepts them depends on its firmware trust settings and revocation updates. The launcher does not change Secure Boot settings. Older BIOS (legacy) and UEFI behave differently; a missing Use a device item is often legacy, not a failed erase.

The launcher failed

  1. Inserting the USB does not start the application. On Windows, open Start Beamo Wipe.exe. On a supported Linux desktop, open Start Beamo Wipe Linux.
  2. Permission or application-trust prompts may appear. Linux desktop and mount settings can prevent running a file from a USB.
  3. A check that is not verified is not a pass. If startup settings cannot be read, administrator permission may be needed. If a guided restart is unavailable, use the boot instructions on this page.
  4. The launcher does not erase anything. If it will not open, use the typical keys or the Windows Settings steps.
  5. If Beamo Wipe has already started from this USB and then keeps closing, use the recovery screen: try again, use keyboard text screens, or view technical details.
Technical detail

The launcher only checks the original USB, whether startup settings can be read, and whether a supported restart route exists. Those checks do not guarantee that the USB will boot. Opening this page in a browser on the USB is enough to follow the boot steps. After boot, recovery cannot identify disks or confirm an erase result.

If you might use this Windows installation again

Confirm you can reach the BitLocker recovery key for this PC before you change firmware, boot order, Secure Boot, or TPM settings. Those changes can make Windows ask for the 48-digit recovery key the next time it starts.

Microsoft Support cannot retrieve, provide, or recreate a lost key. The key might be saved with a Microsoft account on another device, held by work or school IT, printed, or stored on a USB you saved when encryption was turned on.

This helper does not turn BitLocker off, extract keys, or recommend changing Secure Boot. If you still need this Windows later and you cannot find the key, do not change firmware. Use the Windows steps below, another USB port, or the manufacturer’s startup instructions instead.

If you use a screen reader

The boot menu has a Beamo Wipe: speech for screen readers entry. As soon as the menu appears, press S. UEFI computers with a built-in speaker play two short beeps while the menu is showing; many laptops and the older BIOS menu make no sound, so press S a few times after the firmware logo.

The menu waits five seconds, then starts the ordinary guide. If that happens, press F8 in the guide to switch to the spoken view. Speech needs working speakers or headphones. Choosing either entry erases nothing.

If Beamo Wipe keeps closing

After three failed attempts, automatic retries stop. The Beamo Wipe recovery screen lets you try again, use keyboard text screens, or view technical details. Type the choice number and press Enter.

An earlier erase may still be running or may be incomplete. Keep all disks connected. This recovery screen cannot identify disks or confirm an erase result. Retrying does not start a new erase.

Restart and Shut down require confirmation. They are blocked if erasing may still be running or the check fails. Restarting loses unsaved reports and temporary logs. Note the technical details first.

If you selected speech at boot, recovery choices are spoken when the speech tools are available. The keyboard text wizard itself has no speech. If speech cannot start, ask someone to read the recovery screen.

If a wizard screen shows a problem

Failures in Beamo Wipe use three sections, in this order. Disk identity, exclusions, uncertainty, and the exact message stay visible.

  1. What happened — the exact message from this session.
  2. What it means for your disk — whether anything was erased, and what not to assume.
  3. What to do next — safe steps. Do not bypass protection. Keep disks connected if you are unsure.

Technical details (result codes, export markers, logs) are available on demand. They do not replace the three sections. The live USB recovery menu after repeated startup failures is separate: its Technical details and logs choice is not this wizard layout.

What this USB does

Check that you have the copies you need. You will pick a disk. Everything on that disk will be erased. You cannot get the files back.

If that disk holds an operating system, erasing it also removes Windows or Linux, applications, files, and recovery partitions on that disk. Only the disk you confirm is erased. Other disks are not. Putting an operating system back on is a separate task.

If this computer has a battery, plug it into wall power before you erase. Keep the lid open. A power cut stops the erase. The screen may go dark; press a key or move the mouse to bring it back. That is the display, not sleep.

If you want a report afterwards, you need a separate FAT32 USB stick with one volume (any size). Keep it unplugged until the result screen asks for it. A USB that is already plugged in cannot be used for the report.

The live USB asks Linux to ignore lid closure and a short power-button press, and disables sleep. Firmware or a held power button can still stop the erase. Use Cancel erase and wait for the result before shutting down. A power cut can leave the disk partly erased and lose unsaved reports; an interrupted erase does not resume automatically.

This offline helper cannot read battery or wall-power status. The live wizard shows reported readings when available; unknown readings are not proof that power is connected or will last.

For 64-bit Intel/AMD Windows or Linux PCs that start from USB. Not Apple Silicon Macs. Not Chromebooks. Some Intel Macs may show this USB; many will not.

If the computer does not start after erasing

If the erased disk was the one the computer starts from, the computer may show a black screen, a "no operating system" message, or start-up repair instead of starting normally. That is expected: erasing removed the operating system along with everything else on that disk.

To use that computer again, install an operating system first, using installation media or the computer maker's recovery. If you are unsure, ask someone you trust for help before changing anything.

If the erased disk was an extra drive, the computer should start normally. The erased drive will appear empty until it is set up for reuse.

Saving the report

  1. Insert the report USB only when the result screen asks for it.
  2. Check: the wizard accepts exactly one new FAT32 USB.
  3. Save writes the report to that USB. This can take a couple of minutes on a slow stick; never remove any USB while saving.
  4. Verify reads the copy back before it counts as saved.
  5. Safe removal: only the saved message makes the report USB safe to remove.

If saving fails, read the exact error, fix the problem, and choose Save report to USB again. If the report USB is still plugged in, there is no need to unplug it first.

If a report cannot be saved at all, read the Support code and Build lines on the screen and tell support those exact values. They do not include disk serials or paths.

If the USB is rejected:

  • Wrong filesystem or layout: use a different USB stick with one FAT32 volume.
  • Already mounted: unplug only the report USB, plug it back in, then try again.
  • More than one new USB: unplug the extras so exactly one remains.
  • Boot or selected disk involved: shut down first, then sort the USB sticks while the computer is off.

Shutting down and removing USB sticks

  1. Report first: keep the session open, save the report, and wait for the saved message. Only then may the report USB be removed.
  2. Leave the Beamo USB and the erased disk plugged in while Beamo Wipe runs.
  3. The Beamo USB is safe to remove only after the computer is fully off. Removing it earlier ends the session immediately.
  4. If you restart instead of shutting down, leave the Beamo USB plugged in to come back to Beamo Wipe. Anything unsaved is still lost.
  5. If more than one USB is plugged in, or anything was unplugged and plugged back in, do not guess which is which. Shut down first, then sort the USB sticks while the computer is off.
