Beamo Wipe

Boot helper. Not a wipe program.

This page does not erase disks. Restart the PC and open the boot menu.

This USB is a bootable tool. Windows and macOS will not wipe a drive from here. You restart the computer and tell it to start from this USB.

Typical boot-menu keys

PCBoot menu key (typical)
DellF12
HPF9 or Esc

Intel MacOption (⌥) at startup. Not Apple Silicon.

Windows 10 / 11 fallback

  1. Settings → System → Recovery
  2. Advanced startup → Restart now
  3. Use a device → pick this USB

What this USB is

A guided front-end for nwipe, free open-source disk erasure software. Beamo did not write that engine. There is no warranty.

For x86_64 PCs that can boot from USB. Apple Silicon Macs are not supported. Some Intel Macs may show this USB; many will not. Not for Chromebooks.
