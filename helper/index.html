Beamo Wipe

Boot helper. Not a wipe program.

This page does not erase anything. Restart the computer and press the key for your PC.

Windows will not erase a disk from this page. Restart the computer and start from this USB.

Press this key as the computer starts

PCKey
DellF12
HPF9 or Esc
LenovoF12
ASUSF8 or Esc
AcerF12
MSIF11
GigabyteF12
Intel MacOption (⌥) at startup. Not Apple Silicon.

If the key does not work on Windows 10 or 11

  1. Open Settings, then System, then Recovery
  2. Advanced startup, then Restart now
  3. Use a device, then pick this USB

What this USB does

You pick a disk. Everything on that disk is erased. Files cannot be brought back.

This uses nwipe, free disk-erase software. Beamo did not write it. There is no warranty.

For Windows PCs that start from USB. Not Apple Silicon Macs. Not Chromebooks. Some Intel Macs may show this USB; many will not.
