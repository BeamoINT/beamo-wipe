Wenn etwas nicht funktioniert

Wählen Sie das beobachtete Problem. Alle Schritte stehen ohne Internetverbindung auf diesem USB-Stick.

  • Der USB-Stick fehlt in der Liste
  • Die Bootmenütaste funktioniert nicht
  • Der Computer lehnt den USB-Stick ab
  • Der Starter öffnet sich nicht

Der USB-Stick fehlt in der Liste

  1. Lassen Sie den Stick beim Neustart eingesteckt. Nutzen Sie einen USB-A- oder USB-C-Anschluss direkt am Computer und probieren Sie einen anderen Anschluss.
  2. Suchen Sie den Stick im Bootmenü oder auf UEFI-PCs unter Gerät verwenden. Folgen Sie den Schritten für Windows 11 oder Windows 10.
  3. Wenn er weiter fehlt, prüfen Sie auf einem Computer, der die Dateien anzeigt, ob START-HERE.html auf dem Stick liegt. Ändern Sie die Firmware nicht automatisch.

Zurück zu den Problemen

Die Bootmenütaste funktioniert nicht

  1. Sehen Sie in der Tabelle mit typischen Tasten nach. Drücken Sie die Taste ab dem Neustart, bevor Windows lädt.
  2. Bei HP versuchen Sie zuerst Esc, dann F9. Die Taste kann je nach Modell anders sein; prüfen Sie die Herstelleranleitung.
  3. Wenn der Computer zu schnell startet, nutzen Sie die Windows-Schritte unten statt einer Firmwareänderung.

Zurück zu den Problemen

Der Computer lehnt den USB-Stick ab

  1. Falls Sie dieses Windows vielleicht wieder nutzen, stellen Sie vor einer Firmwareänderung sicher, dass Sie den BitLocker-Wiederherstellungsschlüssel erreichen können. Wenn Sie ihn nicht finden, halten Sie an.
  2. Notieren Sie die genaue Meldung. Das Bootmenü bedeutet nicht, dass ein Löschen begonnen hat.
  3. Probieren Sie einen anderen direkten USB-Anschluss und die Startanleitung des Herstellers. Diese Seite ändert Secure Boot nicht und umgeht keine Ablehnung.

Im Abschnitt Secure Boot steht, welche Startkomponenten sich auf diesem USB-Stick befinden.

Zurück zu den Problemen

Der Starter öffnet sich nicht

  1. Das Einstecken startet nichts automatisch. Öffnen Sie unter Windows Start Beamo Wipe.exe oder auf einem unterstützten Linux-Desktop Start Beamo Wipe Linux.
  2. Berechtigungsabfragen können erscheinen. Wenn sich die Anwendung nicht öffnet, verwenden Sie die Bootmenütasten oder die Windows-Schritte unten.
  3. Falls Beamo Wipe bereits vom Stick gestartet ist und sich dann wiederholt schließt, nutzen Sie den Wiederherstellungsbildschirm. Der Starter selbst löscht nichts.

Zurück zu den Problemen

Nachdem dieser USB-Stick startet

Datenträger wählen → Identität bestätigen → Prüfen und löschen. Nichts wird gelöscht, bis Sie bestätigen.

Vom Desktop starten

Öffnen Sie unter Windows Start Beamo Wipe.exe auf diesem USB-Stick. Auf einem unterstützten Linux-Desktop öffnen Sie Start Beamo Wipe Linux. Der Starter zeigt getrennte Prüfungen für den Original-USB-Stick, ob Starteinstellungen gelesen werden können und ob ein unterstützter Neustartweg verfügbar ist. Jede Prüfung erklärt das weitere Vorgehen; Technische Details zeigt die Nachweise.

Eine nicht bestätigte Prüfung ist kein Bestehen. Unter Windows speichern Sie Ihre Arbeit und verwenden Neu starten; wählen Sie dann diesen USB-Stick im Bootmenü. Auf unterstützten Linux-Desktops kann nach erfolgreichen Prüfungen ein geführter Neustart angeboten werden; dafür kann eine Administratorberechtigung nötig sein. Diese Prüfungen garantieren nicht, dass der USB-Stick startet.

Das Öffnen der Anwendung erfordert Ihre Handlung; das Einstecken des USB-Sticks führt sie nicht automatisch aus. Berechtigungs- oder Vertrauensabfragen können erscheinen. Linux-Desktop- und Einhänge-Einstellungen können die direkte Ausführung verhindern.

Der Starter löscht nichts. Gelöscht wird nach dem Neustart in diesen USB-Stick, wo Sie den Datenträger wählen und bestätigen. Sie können die Startanweisungen unten auch ohne Öffnen einer Anwendung verwenden.

Wenn Sie diese Windows-Installation vielleicht wieder verwenden

Stellen Sie sicher, dass Sie den BitLocker-Wiederherstellungsschlüssel für diesen PC erreichen, bevor Sie Firmware, Bootreihenfolge, Secure Boot oder TPM-Einstellungen ändern. Diese Änderungen können dazu führen, dass Windows beim nächsten Start den 48-stelligen Wiederherstellungsschlüssel verlangt.

Der Microsoft-Support kann einen verlorenen Schlüssel weder abrufen noch bereitstellen noch neu erstellen. Der Schlüssel ist möglicherweise in einem Microsoft-Konto auf einem anderen Gerät gespeichert, bei der IT von Arbeit oder Schule hinterlegt, ausgedruckt oder auf einem USB-Stick gespeichert, den Sie beim Aktivieren der Verschlüsselung gesichert haben.

Dieser Helfer schaltet BitLocker nicht aus, extrahiert keine Schlüssel und empfiehlt keine Secure-Boot-Änderung. Wenn Sie dieses Windows später noch brauchen und den Schlüssel nicht finden, ändern Sie keine Firmware. Verwenden Sie stattdessen die Windows-Schritte unten, einen anderen USB-Anschluss oder die Startanweisungen des Herstellers.

Wenn Sie einen Screenreader verwenden

Das Startmenü hat einen Eintrag Beamo Wipe: Sprachausgabe für Screenreader. Sobald das Menü erscheint, drücken Sie S. UEFI-Computer mit eingebautem Lautsprecher geben zwei kurze Pieptöne, solange das Menü angezeigt wird; viele Notebooks und das ältere BIOS-Menü geben keinen Ton, also drücken Sie nach dem Firmware-Logo mehrmals S.

Das Menü wartet fünf Sekunden und startet dann die normale Anleitung. Drücken Sie in dem Fall in der Anleitung F8, um zur gesprochenen Ansicht zu wechseln. Sprache braucht funktionierende Lautsprecher oder Kopfhörer. Beide Einträge löschen nichts.

Windows 11: diesen USB-Stick aus den Einstellungen starten

Diese Schritte verwenden die Windows-Wiederherstellungsumgebung. Gerät verwenden wird auf UEFI-PCs angeboten. Auf Legacy-BIOS kann es fehlen.

  1. Lassen Sie diesen USB-Stick in einem Anschluss am Computer, möglichst nicht in einem Tastatur-Hub.
  2. Einstellungen → System → Wiederherstellung
  3. Wählen Sie unter Erweiterter Start die Option Jetzt neu starten
  4. Option auswählen → Gerät verwenden → dieser USB-Stick, falls er aufgeführt ist

Windows 10: diesen USB-Stick aus den Einstellungen starten

Diese Schritte verwenden die Windows-Wiederherstellungsumgebung. Gerät verwenden wird auf UEFI-PCs angeboten. Auf Legacy-BIOS kann es fehlen.

  1. Lassen Sie diesen USB-Stick in einem Anschluss am Computer, möglichst nicht in einem Tastatur-Hub.
  2. Einstellungen → Update und Sicherheit → Wiederherstellung
  3. Wählen Sie unter Erweiterter Start die Option Jetzt neu starten
  4. Option auswählen → Gerät verwenden → dieser USB-Stick, falls er aufgeführt ist

Wenn Einstellungen nicht verfügbar sind

  • Halten Sie auf dem Anmeldebildschirm oder im Energiemenü Shift gedrückt, während Sie Neu starten wählen. Verwenden Sie dann Option auswählen → Gerät verwenden, falls angeboten.
  • Manche PCs haben eine Hersteller-Wiederherstellungstaste oder Tastenkombination. Das ist unterschiedlich. Lesen Sie die Anweisungen des Computers.
  • Starten Sie neu und versuchen Sie die typische Bootmenü-Taste für Ihren PC. Wenn der USB-Stick fehlt, versuchen Sie einen anderen direkten USB-Anschluss.

Betrachten Sie Firmware-, Bootreihenfolge- oder Secure-Boot-Änderungen nicht als nächsten automatischen Schritt. Wenn Sie vielleicht zu dieser Windows-Installation zurückkehren, bestätigen Sie zuerst den BitLocker-Wiederherstellungsschlüssel.

Wenn der Computer meldet, dass Secure Boot diesen USB-Stick nicht startet

Dieser Build verwendet Debians signierte Startkomponenten. Ob Ihr Computer sie akzeptiert, hängt von seinen Firmware-Vertrauenseinstellungen und Sperrlisten-Updates ab.

Wenn er den USB-Stick ablehnt, versuchen Sie einen anderen direkten USB-Anschluss und lesen Sie die Startanweisungen des Computerherstellers. Der Starter ändert keine Secure-Boot-Einstellungen und umgeht keine Ablehnung. Nehmen Sie nicht an, dass das Erreichen eines Startmenüs bedeutet, dass ein Löschen begonnen hat.

Wenn sich Beamo Wipe immer wieder schließt

Nach drei fehlgeschlagenen Versuchen stoppen die automatischen Wiederholungen. Der Beamo-Wipe-Wiederherstellungsbildschirm lässt Sie es erneut versuchen, Tastatur-Textbildschirme verwenden oder technische Details ansehen. Tippen Sie die Auswahlzahl und drücken Sie Enter.

Ein früheres Löschen läuft möglicherweise noch oder ist unvollständig. Lassen Sie alle Datenträger angeschlossen. Dieser Wiederherstellungsbildschirm kann weder Datenträger identifizieren noch ein Löschergebnis bestätigen. Erneutes Versuchen startet kein neues Löschen.

Neu starten und Herunterfahren erfordern eine Bestätigung. Sie sind blockiert, wenn das Löschen möglicherweise noch läuft oder die Prüfung scheitert. Ein Neustart verliert ungespeicherte Berichte und temporäre Protokolle. Notieren Sie zuerst die technischen Details.

Wenn Sie beim Start Sprache gewählt haben, werden Wiederherstellungsauswahlen gesprochen, wenn die Sprachwerkzeuge verfügbar sind. Der Tastatur-Textassistent selbst hat keine Sprache. Wenn Sprache nicht starten kann, bitten Sie jemanden, den Wiederherstellungsbildschirm vorzulesen.

Wenn ein Assistentenbildschirm ein Problem zeigt

Fehler in Beamo Wipe verwenden drei Abschnitte, in dieser Reihenfolge. Datenträgeridentität, Ausschlüsse, Unsicherheit und die genaue Meldung bleiben sichtbar.

  1. Was geschehen ist — die genaue Meldung dieser Sitzung.
  2. Was das für Ihren Datenträger bedeutet — ob etwas gelöscht wurde, und was Sie nicht annehmen sollten.
  3. Was Sie als Nächstes tun — sichere Schritte. Umgehen Sie den Schutz nicht. Lassen Sie Datenträger angeschlossen, wenn Sie unsicher sind.

Technische Angaben (Ergebniscodes, Exportmarkierungen, Protokolle) sind auf Anfrage verfügbar. Sie ersetzen die drei Abschnitte nicht. Das Live-USB-Wiederherstellungsmenü nach wiederholten Startfehlern ist getrennt: die Wahl Technische Details und Protokolle ist nicht dieses Assistentenlayout.

Was dieser USB-Stick tut

Stellen Sie sicher, dass Sie die Kopien haben, die Sie brauchen. Sie wählen einen Datenträger. Alles auf diesem Datenträger wird gelöscht. Sie bekommen die Dateien nicht zurück.

Wenn dieser Datenträger ein Betriebssystem enthält, entfernt das Löschen auch Windows oder Linux, Anwendungen, Dateien und Wiederherstellungspartitionen auf diesem Datenträger. Nur der von Ihnen bestätigte Datenträger wird gelöscht. Andere nicht. Ein Betriebssystem wieder aufzuspielen ist eine separate Aufgabe.

Wenn dieser Computer einen Akku hat, schließen Sie ihn vor dem Löschen ans Stromnetz an. Lassen Sie den Deckel offen. Ein Stromausfall stoppt das Löschen. Der Bildschirm kann dunkel werden; drücken Sie eine Taste oder bewegen Sie die Maus, um ihn zurückzuholen. Das ist die Anzeige, kein Ruhezustand.

Wenn Sie danach einen Bericht möchten, brauchen Sie einen separaten FAT32-USB-Stick mit einem Volume (jede Größe). Lassen Sie ihn abgezogen, bis der Ergebnisbildschirm danach fragt. Ein bereits angesteckter USB-Stick kann nicht für den Bericht verwendet werden.

Der Live-USB-Stick bittet Linux, das Schließen des Deckels und kurzes Drücken des Netzschalters zu ignorieren, und deaktiviert den Ruhezustand. Firmware oder ein gehaltener Netzschalter können das Löschen trotzdem stoppen. Verwenden Sie Löschen abbrechen und warten Sie auf das Ergebnis, bevor Sie herunterfahren. Ein Stromausfall kann den Datenträger teilweise gelöscht zurücklassen und ungespeicherte Berichte verlieren; ein unterbrochenes Löschen wird nicht automatisch fortgesetzt.

Dieser Offline-Helfer kann Akku- oder Netzstromstatus nicht lesen. Der Live-Assistent zeigt gemeldete Messwerte, wenn verfügbar; unbekannte Messwerte beweisen weder Anschluss noch Dauer des Stroms.

Wenn der Computer nach dem Löschen nicht startet

Wenn der gelöschte Datenträger der war, von dem der Computer startet, zeigt der Computer möglicherweise einen schwarzen Bildschirm, eine Meldung wie „Kein Betriebssystem“ oder die Startreparatur, statt normal zu starten. Das ist zu erwarten: Das Löschen hat das Betriebssystem zusammen mit allem anderen auf diesem Datenträger entfernt.

Um diesen Computer wieder zu verwenden, installieren Sie zuerst ein Betriebssystem, mit einem Installationsmedium oder der Wiederherstellung des Herstellers. Wenn Sie unsicher sind, bitten Sie eine Person Ihres Vertrauens um Hilfe, bevor Sie etwas ändern.

Wenn der gelöschte Datenträger ein zusätzliches Laufwerk war, sollte der Computer normal starten. Der gelöschte Datenträger erscheint leer, bis er für die Wiederverwendung eingerichtet ist.

Bericht speichern

  1. Stecken Sie den Berichts-USB-Stick ein, nur wenn der Ergebnisbildschirm danach fragt.
  2. Prüfen: Der Assistent akzeptiert genau einen neuen FAT32-USB-Stick.
  3. Speichern Sie den Bericht auf diesem Stick. Auf einem langsamen Stick kann das ein paar Minuten dauern; ziehen Sie währenddessen keinen USB-Stick ab.
  4. Verifizieren Sie die Kopie durch Zurücklesen, bevor sie als gespeichert gilt.
  5. Sicheres Abziehen: Erst die gespeicherte Meldung macht den Berichts-USB-Stick sicher entfernbar.

Wenn das Speichern fehlschlägt, lesen Sie die genaue Fehlermeldung, beheben Sie das Problem und wählen Sie Bericht auf USB speichern erneut. Wenn der Berichts-USB-Stick noch angesteckt ist, müssen Sie ihn nicht zuerst abziehen.

Wenn ein Bericht überhaupt nicht gespeichert werden kann, lesen Sie die Zeilen Supportcode und Build-Kennung auf dem Bildschirm und nennen Sie dem Support genau diese Werte. Sie enthalten keine Datenträger-Seriennummern oder Pfade.

Wenn der USB-Stick abgelehnt wird:

  • Falsches Dateisystem oder Layout: Verwenden Sie einen anderen USB-Stick mit einem FAT32-Volume.
  • Bereits eingehängt: Ziehen Sie nur den Berichts-USB-Stick ab, stecken Sie ihn wieder an und versuchen Sie es erneut.
  • Mehr als ein neuer USB-Stick: Ziehen Sie die übrigen ab, sodass genau einer bleibt.
  • Start- oder ausgewählter Datenträger betroffen: Fahren Sie zuerst herunter und sortieren Sie die USB-Sticks, während der Computer aus ist.

Herunterfahren und USB-Sticks abziehen

  1. Bericht zuerst: lassen Sie die Sitzung offen, speichern Sie den Bericht und warten Sie auf die gespeicherte Meldung. Erst dann darf der Berichts-USB-Stick abgezogen werden.
  2. Lassen Sie den Beamo-USB-Stick und den gelöschten Datenträger angeschlossen, solange Beamo Wipe läuft.
  3. Der Beamo-USB-Stick darf erst abgezogen werden, wenn der Computer vollständig ausgeschaltet ist. Früheres Abziehen beendet die Sitzung sofort.
  4. Wenn Sie neu starten statt herunterzufahren, lassen Sie den Beamo-USB-Stick angeschlossen, um zu Beamo Wipe zurückzukehren. Alles Ungespeicherte geht trotzdem verloren.
  5. Wenn mehr als ein USB-Stick angeschlossen ist oder etwas ab- und wieder angesteckt wurde, raten Sie nicht, welcher welcher ist. Fahren Sie zuerst herunter und sortieren Sie die Sticks, während der Computer aus ist.
