The USB is missing or not listed



    

  1. Keep the USB connected. Do not remove it while the computer restarts.
    2. 

  2. Use a USB-A or USB-C port on the computer itself, not a keyboard, monitor, or hub.
    3. 

  3. Try a different direct USB port.
    4. 

  4. Restart and look for this USB in the boot menu, or in Windows Use a device.
    5. 



Windows 11: Settings → System → Recovery → Advanced startup → Restart now → Use a device. Windows 10: Settings → Update & Security → Recovery → Advanced startup → Restart now → Use a device. Use a device is for UEFI PCs.

The boot-menu key does nothing



Keep the USB connected. Restart, then press the boot-menu key for your PC and choose the USB. Those keys vary by manufacturer; they are not universal.


Dell, Lenovo, Acer
F12
HP
Esc, then F9
ASUS
F8 or Esc
MSI, Gigabyte
F11 (MSI), F12 (Gigabyte)


    

  1. Start tapping the key as soon as you restart — before Windows or a logo finishes.
    2. 

  2. If the computer starts too quickly, use the Windows Settings steps instead of changing firmware.
    3. 

  3. Check the sticker, the startup screen, or the manufacturer’s instructions if a listed key does nothing.
    4.

The computer refused the USB



    

  1. If you might start this Windows installation again, confirm you can reach the BitLocker recovery key before changing firmware, boot order, or Secure Boot. Those changes can trigger recovery. If you cannot find the key, stop and use another USB port or the Windows steps.
    2. 

  2. Write down the exact message. Reaching a boot menu does not mean an erase has started.
    3. 

  3. Try a direct USB port and restart. On older BIOS computers, Use a device may be missing — use the boot-menu key.
    4. 

  4. Use the computer manufacturer’s startup instructions. This launcher does not change Secure Boot or BitLocker.
    5.

The launcher failed



    

  1. A check that is not verified is not a pass. Choose Check again, or use the boot-menu steps on this page.
    2. 

  2. If startup settings cannot be read, administrator permission may be needed. If a guided restart is unavailable, keep the USB connected and use the typical keys.
    3. 

  3. If this window never opened, open START-HERE.html on the USB. Inserting the USB does not start the application by itself.
    4. 

  4. This launcher does not erase anything. You still choose and confirm the disk after startup.
    5.
